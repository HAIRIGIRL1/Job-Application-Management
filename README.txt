JOB APPLICANT MANAGEMENT SYSTEM

1. Extract this folder.
2. Open the folder in VS Code.
3. Open login.html in a browser (Live Server is recommended).
4. Click Sign In to enter the dashboard. Demo sign-in accepts any valid email and non-empty password; it is not real authentication.
5. Sample applicants are included and stored in this browser Local Storage. Add/edit/delete records to test features.

Files: login.html, index.html, applicants.html, add-applicant.html, applicant-details.html, filter.html, forgot-password.html, reports.html, notifications.html, settings.html, admin.html, styles.css, storage.js, validation.js, sidebar.js, script.js.

Note: This is an academic front-end demo. Local Storage is not a secure shared database and does not sync between computers. Use fictional sample data only.
